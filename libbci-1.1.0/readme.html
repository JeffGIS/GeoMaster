Bicubic Interpolation Library


Documentation

Introduction

  libbci uses to do 2-dimentional interpolation of 3D data.
The main goals of the library are:
  - use real 2D method instead of bilinear interpolation method,
  - have choise: use low or high level routines.

Installation

  To install the library you have to extract archive or checkout sources from CVS and just type:
# make
# make install

Usage

  If you have 3D data (set of (x, y, z) points), you need to fill doublexyz structure (see bci.h file for details) with this data, but this data must be already sorted. After that use function void td_fillgrid() to get array with better resolution setted by you own.
void td_fillgrid(const doublexyz *inputarray, int icolumns, int irows, 
doublexyz *outputarray, int ocolumns, int orows)
inputarrayarray of points on which interpolation will be based,
icolumnsnumber of columns in inputarray array,
irowsnumber of rows in inputarray array,
outputarrayarray of points where results will be saved,
ocolumnsnumber of columns in outputarray array,
orowsnumber of rows in outputarray array.

Example

  xyz[16] is a Row-major array of input points and fxyz[256] is an array to be filled after interpolation. So after calling td_fillgrid routine you have array with better resolution.
#include<bci.h>

int main()
{
    int i, j;
    double x, y;
    doublexyz xyz[16], fxyz[256];

    for(i = 0; i < 4; i++)
        for(j = 0; j < 4; j++) {
            x = i + 2.;
            y = j + 2.;
            xyz[4*i + j].x = x;
            xyz[4*i + j].y = y;
            xyz[4*i + j].z = 2. + 2.*x*x + y*y*y + x*y;
            printf("%d: %f %f %f\n", 4*i + j,
                   xyz[4*i + j].x, xyz[4*i + j].y, xyz[4*i + j].z);
        }

    td_fillgrid(xyz, 4, 4, fxyz, 16, 16);

    for(i = 0; i < 16; i++) {
        for(j = 0; j < 16; j++)
            printf("%f ", fxyz[16*i + j].z);
        printf("\n");
    }
}
