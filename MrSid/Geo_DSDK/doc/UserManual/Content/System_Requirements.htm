System Requirements

The MrSID SDK is a set of C++ libraries that must be used in conjunction with the specific development environment for your platform. The supported configurations are listed below.

For SDK usage, LizardTech recommends the use of hardware at least equal to the equivalent of a 1GHz PC processor with 1 GB of RAM.

NOTE:  Each SDK distribution supports only a single target platform. Please contact LizardTech for additional distributions for other platforms.
