System Requirements

The MrSID Decode SDK is a set of C++ libraries that must be used in conjunction with the specific development environment for your platform. The supported configurations are listed below.

For SDK usage, LizardTech recommends the use of hardware that is at least the equivalent of a 1GHz PC processor with 1 GB of RAM.

NOTE:  Each SDK distribution is supported on only a single target platform. Please contact LizardTech for additional distributions for other platforms.

Windows
Windows / Visual Studio 2008 / 32-bit
  • built with: Windows 2003/64, VC9.0 – 32-bit
  • supported on: Windows 2000/32-bit, Windows 2k3/32-bit, Windows XP/32-bit, Windows Vista/32-bit
Windows / Visual Studio 2008 / 64-bit
  • built with: Windows 2003/64, VC9.0 – 64-bit
  • supported on: Windows 2003/64-bit, Windows XP/64-bit, Windows Vista/64-bit
Windows / Visual Studio 2010 / 32-bit
  • built with: Windows 2003/64, VC10.0 – 32-bit
  • supported on: Windows 2003/64-bit, Windows XP/64-bit, Windows Vista/64-bit, Windows 7/64-bit
Windows / Visual Studio 2010 / 64-bit
  • built with: Windows 2003/64, VC10.0 – 64-bit
  • supported on: Windows 2003/64-bit, Windows XP/64-bit, Windows Vista/64-bit, Windows 7/64-bit

NOTE:  The 32-bit version of the SDK can be run on a 64-bit system.
